## Phase 4: logical FP16 composition and late PQ (HDR10 only)

- Order: game (+ Dalamud mode 4) renders gamma-domain into the logical FP16 buffer → at ReShade `present`, `OnPresentComposition` converts gamma→linear scRGB in place (`final_scrgb_pixel_shader`: same decode/UI scaling as the upstream scRGB path) → ReShade effects/GUI → facade `Present`/`Present1` encodes scRGB (80 nits) → BT.2020/PQ into the physical RGB10A2 buffer (`present_pq`) → inner Present.
- One logical FP16 texture per physical buffer index (aliases shared). The facade reports FP16/scRGB, owns the physical PQ color space (`SetColorSpace1` accepts scRGB only), and drops dirty rects on `Present1`. Resize refuses while logical buffers are referenced, then recreates them.
- Routing follows the facade only: composition is initialized before the facade is published; failure releases it (`FALLBACK upstream`) and returns the original swapchain. Per swapchain: no facade → `route=upstream_hdr10`; ready facade → `route=custom custom_ready=1` (module-owned FP16 view info, no dependency on upstream device data); unready facade (e.g. failed resize) → `route=none` (no addon pass; facade Present also fails, so no PQ conversion). A facade is never presented through upstream, including when it has no presentation data. Upstream settings, tonemap shaders, `OnPresentStateReset`/copy tracker and scRGB mode are unchanged. No per-draw composition.
- Validation: FFXIV `clang-x64-debug` build passed (56 warnings, baseline); not deployed.
- Runtime check (HDR10, Dalamud mode 4, with and without OptiScaler): expect `INSERT source=...`, `FP16_BUFFER ... logical_format=10 physical_format=24` per index, `RESHADE_INIT ... identity_ok=1 format=10`, Presentation `INIT route=custom custom_ready=1 passes=N`, up to four `COMPOSE ... submitted=1`, `ENCODE_SUBMITTED generation=0 encoding=hdr10_pq`, first `PRESENT hr=0x00000000`. Visual: Dalamud windows visible and matching upstream scRGB; ReShade GUI/effects correct brightness. Resize: `RESIZE_BEGIN`/`RESIZE_END ready=1 hr=0x00000000`, new `FP16_BUFFER`, `INIT route=custom resize=1`, `ENCODE_SUBMITTED generation=N`. Exit: Presentation `DESTROY`, facade `DESTROY`, `RELEASED_FP16`, `RELEASED_INNER live=0`. Investigate any `ENCODE_FAILED`, `COMPOSE submitted=0`, `RESIZE_REFERENCED`, `FALLBACK`, `route=none`, or `route=upstream_hdr10 ... facade=0` while the facade log shows an `INSERT`. An upstream `ChangeColorSpace ... Failed to set DirectX color space` warning is expected (the facade rejects PQ on the logical chain).

## Phase 5A: manual HDR10/SDR encoding (HDR10 facade route only)

- Setting `outputEncoding` (HDR10 (PQ) / SDR (Gamma 2.2)) switches live; `outputMode` stays restart-only. Physical RGB10A2 buffers, logical FP16 buffers and ReShade's scRGB view are unchanged by a switch.
- Per frame: `reshade_present` (after the overlay) picks the next frame's encoding, pre-checks `CheckColorSpaceSupport`, and applies its composition settings; `OnPresentComposition` tags the frame; facade `Present` calls `SetColorSpace1` (PQ BT.2020 or G22 BT.709) and only then selects `present_pq` or `present_sdr`, always matching the applied color space. Resize and init reapply the applied encoding.
- SDR composition reuses the upstream tone mapper: peak, game and UI white become 80 nits (re-applied each frame over the setting bindings), so DICE rolls highlights off to scRGB 1.0; late SDR encode is `saturate` + gamma 2.2. HDR10 restores the user values via `Setting::Write()`. No HDR metadata changes.
- Failure: unsupported color space → `ENCODING_REJECTED`, no switch. `SetColorSpace1` failure → `ENCODING_SWITCH_FAILED`, facade keeps the old encoding, addon logs `ENCODING_REVERT`, restores composition and does not retry until the setting changes.
- Runtime check: toggle both directions repeatedly, with OptiScaler/FG on and off, and across a resize. Expect `ENCODING_REQUEST`, then `ENCODING_SWITCH from=... to=... color_space=0` (SDR) or `12` (PQ) and `ENCODE_SUBMITTED encoding=...`; after resize `RESIZE_END encoding=<applied>` and `INIT route=custom ... encoding=<applied>`. Visual: SDR UI/Dalamud white near SDR white with highlights rolled off, HDR10 unchanged from Phase 4.
