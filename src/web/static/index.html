Renovation Engine for DirectX games Game-specific rendering, rebuilt. RenoDX is an open-source framework for modifying DirectX game rendering through ReShade addons. It provides the foundation for HDR output, shader replacement, resource upgrades, overlays, and persistent graphics settings. Browse Mods View Source
The product A framework for game-specific graphics mods. Each RenoDX mod is built around the rendering pipeline of an individual game. This allows modifications to operate on the relevant scene, interface, post-processing, and output passes instead of applying one generic effect to every title. HDR output Mods can provide game-aware tone mapping and HDR display output while retaining the intended color grading and presentation. Rendering changes Runtime shader replacement and resource upgrades support targeted fixes and deeper rendering-path modifications. Game controls In-game overlays expose settings appropriate to each mod and retain configuration between sessions.
